<Heading size="xlarge">Blade for AI Agents</Heading>
Blade ships its component, pattern and token documentation for AI coding agents in two forms: the
**Blade plugin** (a Claude Code plugin whose skills also load in Cursor, Codex, Copilot and Gemini CLI)
and the older **Blade MCP** server. Prefer the plugin; the MCP is in maintenance mode.

<br />

<Heading size="large">Blade Plugin (recommended)</Heading>

<Heading size="medium">Claude Code</Heading>

From a checkout of the blade repository:

```sh
claude --plugin-dir packages/blade-plugin
```

Marketplace install commands will be published here once the plugin marketplace is live.

<Heading size="medium">Cursor, Codex, Copilot, Gemini CLI</Heading>

```sh
npx skills add razorpay/blade --skill blade
```

The skill lands in `.agents/skills/blade` (with a `.claude/skills/blade` symlink). Ask your agent to build UI and it reads the component docs it needs.

The `blade` skill bundles the docs and guidelines plus workflows for upgrading Blade (changelog summaries), scaffolding a Vite + React app and Figma-to-code (Razorpay-internal).

<br />

<Heading size="large">Blade MCP (maintenance mode)</Heading>
Blade MCP is a [Model Context Protocol (MCP)](https://modelcontextprotocol.io/introduction) server that
exposes the same documentation as tools. Use it only where your agent cannot load skills.

<Heading size="large">Integrations</Heading>

<br />

<Heading size="medium">Cursor or VS Code</Heading>

Create or update your `mcp.json` file with:

```json
{
  "mcpServers": {
    "blade-mcp": {
      "command": "npx",
      "args": ["-y", "@razorpay/blade-mcp@latest"]
    }
  }
}
```

<Heading size="medium">Claude Desktop</Heading>

Add the following to `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "blade-mcp": {
      "command": "npx",
      "args": ["-y", "@razorpay/blade-mcp@latest"]
    }
  }
}
```

> * Learn about how to configure MCP servers in [Claude Desktop](https://modelcontextprotocol.io/quickstart/user)
> * If you're using `nvm`, you might want to [follow these steps](https://github.com/modelcontextprotocol/servers/issues/64) instead of `npx`
> * Learn how to install [Claude Desktop](https://claude.ai/download)

<br />

<Heading size="medium">How to use</Heading>

* Follow [Integrations Guide](#integrations) to configure MCP servers in Cursor
* Open Cursor, Click "Open Project" and select an empty folder
* Press CMD + I (or CTRL + I) to open Cursor's chat
* Type "Hi blade" and get started

<Heading size="medium">Usage Example</Heading>

```
Can you create a signup form with best UX practices using Blade?
```

The AI agents will use the MCP server to retrieve components and generate appropriate code.
