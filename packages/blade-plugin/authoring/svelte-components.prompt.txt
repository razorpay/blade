## Examples

One `### Title` + one-line description + one ```svelte block per distinct use case (usually 2-3).
Each example combines several props in a realistic Razorpay scenario (payments, settlements,

- A complete component: `<script lang="ts">` with all imports, then markup.
- Svelte 5 runes only: `$state`, `$derived`, `$props`. Never `export let`, `$:`, `on:click`,

  blade-svelte exports (see references/general/AvailableIcons.md).
- No inline `style=` attributes or hardcoded colors. `Box` has NO style props (no display, gap,
  padding, flexDirection...); lay it out with theme.css utility classes via `className`, e.g.
  `<Box className="display-flex flex-col gap-spacing-4">` (list in general/Usage.md "Layout").
- Pass only props that exist on the component's Props type. The lint checks every attribute and
  snippet name against it (e.g. `Text` sizes/weights must match `TextProps`).
