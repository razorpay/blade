# When to use General Documentation

General documentation for using Blade in Svelte apps.

## Usage

Setup for `@razorpay/blade-svelte`: installing, theme CSS and fonts, `BladeProvider`, dark mode with `useTheme`, Svelte conventions every component follows (callback props, snippets, runes), using tokens as CSS variables, and `styleOverride` / `componentConfig`. Read this first when setting up an app or when unsure how a Svelte API maps from React Blade.

## Tokens

The full token reference (colors, spacing, typography, border, elevation, motion). Shared with the React skill; use tokens as CSS variables in Svelte.

## AvailableIcons

The exact list of icons that `@razorpay/blade-svelte` exports, with usage. Check it before using any icon; the Svelte set is much smaller than React's.

## WhiteLabelling

Customising Blade's theme for other brands with `createTheme`. You don't need to follow this unless explicitly asked.
