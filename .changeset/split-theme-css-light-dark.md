Split `tokens/theme.css` into `tokens/theme-light.css` and `tokens/theme-dark.css` so consumers that only ship light mode can skip the dark-mode override block.

- `theme-light.css` — base stylesheet: global tokens (`:root`), light theme tokens, mobile typography overrides and the utility classes.
- `theme-dark.css` — additive dark-mode override block only; import it alongside `theme-light.css` (it holds no globals or utilities of its own).
- `theme.css` — unchanged combined file, kept for backwards compatibility. Importing light + dark together is equivalent to it.

A light-only consumer saves ~29 KB uncompressed (~39%) / ~2.2 KB gzipped (~26%) of token CSS per the current token set. Both split files are generated by `yarn generate:tokens-css` alongside `theme.css` and covered by the existing drift-guard test.
